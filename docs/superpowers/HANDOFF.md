### Как продолжить
1. `git switch feature/people`, `git status` — должно быть чисто; `npm test` — 415 тестов проходят.
2. Прочитать этот файл, затем план экранов; ТЗ и макеты — по ссылкам из плана, когда нужны детали.
3. Выполнять план навыком `superpowers:executing-plans`. Журнал `.superpowers/sdd/2026-10-23-people-screens/progress.md`
   показывает, какие задачи уже закрыты (строки `Task N: complete`) — их не переделывать.
4. В конце сессии: обновить раздел «Где остановились» ниже и закоммитить этот файл.

### Что легко забыть
- **Никаких поясняющих надписей на экранах**: пользователь убирает подсказки, «кто заполняет поля», лишние подписи и
  украшения.
- Визуал новых доработок — сначала в том же холсте Claude Design, код — после одобрения.
- Репозиторий публичный: только вымышленные примеры. Локальный хук `.git/hooks/pre-push` блокирует push со словами из
  `.git/info/private-terms` — новые реальные названия добавлять туда.
- Push в `main` = деплой на iPhone. Только после явного «да».
- Комментарии пользователя в холсте не отправлены Claude: читать их можно, отвечать и закрывать — нет.
