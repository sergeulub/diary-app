# Накопления: «Отложил» и «Взял» — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** «Отложено» считается по ручным операциям «Отложил» / «Взял», а не как доход − траты; есть баланс накоплений за всё время.

**Architecture:** Два новых вида операции (`save`, `withdraw`) в той же таблице `transactions`, без категории (`categoryKey: ''`).
Чистые функции в `src/domain/finance.ts` считают месячное «Отложено» и баланс; экспорт `formatVersion: 4`; экраны
«Финансы» и лист ввода — по одобренному артборду «8 · Накопления» в Claude Design
(https://claude.ai/artifact/54x6G4dAzDa72P6feRpBM1).

**Tech Stack:** React + TypeScript + Vite, Dexie, Tailwind, Vitest (`fake-indexeddb` для `db/`).

**Spec:** `docs/superpowers/specs/2026-10-17-savings-design.md`

## Global Constraints

- Интерфейс по-русски. Подписи: «Накопления» (вкладка вида), «Отложил», «Взял», «Отложено», «Всего в накоплениях»,
  заголовок правки «Отложил» / «Взял из накоплений», «Удалить операцию».
- «Отложил»/«Взял» не входят в доход, траты, «Траты по важности», «По категориям», «Доходы», сумму дня в списке и строку
  трат на «Итоге».
- Схема Dexie не меняется (новой `db.version` нет). Доступ к данным — только через `src/db/`.
- `FORMAT_VERSION = 4`; импорт принимает 1–4.
- Без поясняющих надписей в листе ввода (комментарий автора к макету). Лист — полноэкранный `Sheet`, как сейчас.
- Версия приложения 1.4.0.

## Review Focus

3. Удалённая операция `save` (с `deletedAt`) не попадает ни в месяц, ни в баланс — тест в задаче 1.
4. Операции накоплений не попадают в сумму трат дня (`groupByDay`, `dayTotals`) — тест в задаче 1.
5. Импорт отвергает `save` с непустой категорией и `expense` с пустой — тест в задаче 2.
