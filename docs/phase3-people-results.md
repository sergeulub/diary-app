# Модуль «Люди» — проверка на iPhone

Модель iPhone: iPhone 11  ·  Версия iOS: 26.7.1  ·  Дата: __.__.2026  ·  Проверена версия 1.5.1

Новая версия применяется не сразу: закройте приложение из переключателя и откройте **два раза**; в «Настройках»
внизу должно быть «Дневник 1.5.1». Перед проверкой сделайте экспорт — на всякий случай.

| # | Проверка | Как делать | Результат |
|---|---|---|---|
| 1 | Обновление без потерь | Открыть дважды: версия 1.5.1; дни, финансы, цели на месте; в «Настройках» сверху карточка «Люди» с нулями | |
| 2 | Вход и выход | «Открыть «Люди»» → своя панель «Люди · События · + · Дневник», панели дневника нет; «Дневник» → обратно в «Настройки» | |
| 3 | Быстрое добавление голосом | «+» → **клавиатура открылась сама** → имя → «Что запомнил» диктовкой → «Сохранить». Засечь время (цель — меньше минуты) | |
| 4 | «Похоже, уже есть» | Добавить то же имя в другом порядке → шторка → «Это он» → новая встреча у него с заметкой | |
| 5 | Карточка и лента | Тап по человеку → «Изменить» → компания, сфера, контакт, «Знаком с» → лента-хроника, «не разобрано» у заметки | |
| 6 | Фильтры | Кнопка фильтров → сфера → плашка «Сфера: …» над списком; тап по плашке убирает её; архив скрыт по умолчанию | |
| 7 | Событие | «События» → «+» → название → «Добавить человека» → выбрать → встреча с событием; экран события — люди | |
| 8 | Сферы и круги | «⋯» → «Сферы и круги» → объединить две сферы; круг — переименовать, поднять выше | |
| 9 | Экспорт | Экспорт → на ПК в zip папка `people/` (`index.md` и файлы людей), в `backup.json` `"formatVersion": 5` | |
| 10 | Изменения с ПК | Файл `people-patch-….json` из Telegram → «Сохранить в Файлы» → «⋯» → «Изменения с ПК» → предпросмотр → ✎ → «Применить выбранное» → итог | |
| 11 | Через «Настройки» | Тот же файл через «Настройки» → «Импорт из файла» → открывается предпросмотр «Людей», плашка «уже применён» | |
| 12 | Полоса Claude | После применения файла новая запись у человека — выше полосы «разобрано Claude · …» | |
| 13 | Открыть день | Запись «из дневника» → «Открыть день» → «Календарь» с формой этого дня | |
| 14 | Авиарежим и тёмная тема | Включить авиарежим → добавить человека; тёмная тема — всё читается | |
