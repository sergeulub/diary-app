# Фаза 1 — проверка MVP на iPhone

Модель iPhone: iPhone 11  ·  Версия iOS: 26.7.1  ·  Дата: 06.10.2026  ·  Проверена версия 1.0.0

Новая версия применяется не сразу: закройте приложение из переключателя и откройте **два раза**; в «Настройках»
внизу должно быть «Дневник 1.0.0». Иконку «Проба 2» можно удалить — её больше нет.

## Выводы → версия 1.1.0
- **Серия** засчитывала дни, заполненные задним числом. Новое правило (спецификация §4): день идёт в серию, только
  если в свой логический день заполнены все активные метрики и текст ≥ 40 символов; момент — `completedAt` дня.
- **Telegram** присылал два сообщения (имя файла и файл): `navigator.share` получал `title`. Теперь передаётся
  только файл.
- **Напоминание**: основной способ — будильник iOS с мелодией (звучит, пока не выключишь), дополнительно —
  «Напоминания». Спецификация §9 и инструкция в «Настройках» обновлены.
