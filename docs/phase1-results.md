# Фаза 1 — проверка MVP на iPhone

Модель iPhone: iPhone 11  ·  Версия iOS: 26.7.1  ·  Дата: …

Новая версия применяется не сразу: закройте приложение из переключателя и откройте **два раза**; в «Настройках»
внизу должно быть «Дневник 1.0.0». Иконку «Проба 2» можно удалить — её больше нет.

| # | Проверка | Как делать | Результат |
|---|---|---|---|
| 1 | Обновление | Открыть дневник с иконки дважды. Виден экран «Итог дня», версия 1.0.0 | |
| 2 | Вечерняя запись | Мордочки, Лёг / Встал через системный выбор времени, текст диктовкой. Длительность сна верная | |
| 3 | Текст не теряется | Надиктовать фразу и **сразу** смахнуть приложение из переключателя → открыть: фраза на месте | |
| 4 | Авиарежим | Включить авиарежим → закрыть приложение → открыть → запись и календарь работают | |
| 5 | Календарь | Дни окрашены по настроению; тап по прошлому дню → правка → «‹ Календарь» → цвет обновился | |
| 6 | Серия | Чип показывает число дней; если сегодня пусто — подсказка «Заполни сегодня, чтобы продлить» | |
| 7 | Метрики | Добавить метрику «Энергия» → карточка с цифрами на «Итоге»; убрать в архив → исчезла | |
| 8 | Экспорт → ПК | Настройки → «Экспорт в zip» → Telegram → Избранное → Telegram Desktop → распаковать: `backup.json` и `entries_….md`, кириллица читается. Если после выбора файла появилась кнопка «Отправить файл» — нажать её и отметить это здесь | |
| 9 | Отмена экспорта | Нажать «Экспорт в zip» и закрыть окно «Поделиться» → «Отменено», дата последнего экспорта не изменилась | |
| 10 | Импорт в чистое приложение | Сохранить zip из Telegram в «Файлы» → открыть адрес во **вкладке Safari** (у неё своё пустое хранилище) → Настройки → «Импорт из файла» → сводка → «Импортировать» → дни и тексты на месте | |
| 11 | Баннер бэкапа | Во вкладке Safari после импорта (экспорта там не было, дней ≥ 3) на «Итоге» есть баннер «Сделай бэкап» | |
| 12 | Тёмная тема | Включить тёмное оформление iOS → цвета тёмной палитры, карточки без тени, мордочки читаются | |
| 13 | Напоминание | Настроить автоматизацию по инструкции из «Настроек»; в 23:00 приходит уведомление «Запиши день» | |
