# Diary — личный дневник-приложение для iPhone: PWA, работает офлайн, данные только в телефоне

**Стек (предложен, ждёт подтверждения):** React + TypeScript + Vite, Dexie.js (IndexedDB), vite-plugin-pwa, Tailwind CSS, тесты — Vitest ·
**Хостинг кода:** GitHub Pages · **Запуск / проверка:** кода пока нет — появится в Фазе 0

Полная концепция — `ОПИСАНИЕ.md`: варианты установки на iOS, аналоги на GitHub, дизайн, риски и решения,
этапы, источники. Читать перед решениями об архитектуре, этапах и новых модулях.

## Что это
Дневник одного человека (автора): мысли в течение дня, итог дня (настроение, энергия, сон, свои метрики),
календарь, экспорт. В App Store не публикуется: открыть в Safari → «На экран Домой», дальше работает без интернета.
Сначала минимальная база; анализ, дашборды, финансы, здоровье, ИИ наслаиваются потом.

## Договорённости с пользователем
- Интерфейс и тексты — на русском. Дизайн — современный минимализм, ничего лишнего.
- У пользователя Windows, Mac нет; телефон — iPhone (модель и версия iOS не уточнены).
- Без серверов, аккаунтов, аналитики и отправки данных. Интернет нужен только для установки и обновления кода.
- Анализ записей делает Claude Code на ПК по экспортированным файлам, не приложение.

## Архитектурные правила (не нарушать)
1. **Адрес приложения фиксирован навсегда.** IndexedDB привязан к origin: другой домен — пустое приложение.
   Переезд — только через экспорт/импорт.
2. **Схема версионируется** через `db.version(n).upgrade(...)` в Dexie; прежние версии не удалять.
3. **У каждой записи** `id` (UUID), `createdAt`, `updatedAt`, `deletedAt` (мягкое удаление) — задел под синхронизацию.
4. **Логический день** — граница 04:00 (настраивается): запись в 01:30 относится к прошлому дню.
   Время — ISO 8601 со смещением часового пояса.
5. **Экспорт — контракт:** JSON (полный, для импорта и бэкапа) и Markdown (`ГГГГ-ММ-ДД.md` на день, для Claude).
   Формат менять только с повышением `formatVersion`; импорт старых версий не ломать.
6. **Новые трекеры** — строкой в `metricDefinitions`, без миграции схемы.
7. **Логика** (даты, экспорт/импорт, метрики) — чистые функции без DOM, с тестами.
8. **Доступ к данным** — только через слой `db/`: чтобы позже обернуть в Capacitor без переписывания.
9. При старте — `navigator.storage.persist()`; напоминать о бэкапе, если с последнего прошло > 7 дней.

## Модель данных v1
| Таблица | Поля |
|---|---|
| `entries` | `id`, `day` (ГГГГ-ММ-ДД), `createdAt`, `updatedAt`, `deletedAt`, `text`, `tags[]` |
| `days` | `day` (ключ), `mood` 1–5, `energy` 1–5, `sleepStart`, `sleepEnd`, `summary`, `tags[]`, `metrics{key: value}`, `updatedAt` |
| `metricDefinitions` | `key`, `name`, `type` (scale / number / bool / time), `unit`, `order`, `archived` |
| `meta` | `schemaVersion`, `lastBackupAt`, настройки (граница дня и др.) |

Настроение 1–5 + теги + заметка — совместимо с Dailybean (возможен импорт старой истории).

## Экраны MVP
1. **Сегодня** — лента мыслей за день, поле ввода внизу (как «Избранное» в Telegram).
2. **Итог дня** — за 30 секунд: настроение, энергия, сон, отметки метрик, текст.
3. **Календарь** — месяц, дни окрашены по настроению; тап по дню → записи.
4. **Настройки** — метрики, граница дня, экспорт/импорт.

Стиль: системный шрифт (`-apple-system`), монохром + один акцент, авто-тёмная тема, нижняя панель вкладок,
`safe-area-inset`, крупные зоны нажатия.
