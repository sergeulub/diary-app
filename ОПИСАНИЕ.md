# Diary — концепция проекта

> Проработка от 06.10.2026, до начала разработки. Рабочие правила для Claude — в `CLAUDE.md`, здесь — обоснования.

## Зачем
Очень не хватает дневника, в котором можно в течение дня записывать мысли, а вечером подводить итог: как прошёл
день, настроение, здоровье. Цель — видеть тенденции и анализировать. Раньше дневник вёлся в Dailybean
(настроение 1–5, теги, заметки), эмоции фиксировались голосовыми в «Избранное» Telegram.

Требования:
- своё приложение на iPhone, **без публикации в App Store**, данные — локально в телефоне;
- современный минималистичный дизайн, без лишних функций;
- сначала надёжная база, потом слои: анализ текста, нейросеть, дашборды, автовыгрузка в личную папку
  (прогресс в карьере, учёбе, личной жизни), финансовый трекер, здоровье.

## Как поставить на iPhone без App Store
Ограничение: у пользователя Windows, Mac нет. Собрать нативное iOS-приложение без macOS нельзя — только на
облачной macOS-машине.

| Вариант | Как работает | Плюсы | Минусы |
|---|---|---|---|
| **A. PWA** ✅ | Код на GitHub Pages; Safari → «На экран Домой»; дальше офлайн, данные в IndexedDB телефона | Без Mac и денег; без переподписи; обновления сами; лучший вариант для вайбкодинга | Нет Apple Health и локальных уведомлений; при нехватке памяти iOS теоретически может стереть данные |
| **B. Нативное + бесплатный Apple ID** | Сборка unsigned `.ipa` на macOS-раннере GitHub Actions → установка через SideStore (с Windows — iloader) | Настоящее приложение: HealthKit, виджеты, уведомления | Переподпись каждые 7 дней (LocalDevVPN + «Refresh» в SideStore); обновление iOS может сбросить pairing-файл; Apple закрывает лазейки |
| **C. Apple Developer, $99/год** | Облачная сборка, подпись на год, TestFlight / ad hoc | Стабильно, все нативные возможности | Из России оплата только через посредников (комиссия 20–25%) или зарубежной картой |
| **D. Готовое без кода** | Obsidian: ежедневные заметки + шаблон + Dataview/Tracker | Ноль кода, Markdown-файлы сразу читаются Claude | Быстрая отметка настроения неудобна, интерфейс не свой |

Отпадают: Expo Go (не самостоятельное приложение, нужен сервер разработки), TrollStore (не работает на свежих
iOS), джейлбрейк.

**Решение:** старт с A. Код пишется так, чтобы позже обернуть его в Capacitor (B или C), если понадобятся
Apple Health, виджеты или уведомления. Веб-код при этом переиспользуется.

Детали PWA на iOS:
- С iOS 26 любой сайт, добавленный на экран «Домой», по умолчанию открывается как веб-приложение.
- Ограничение «7 дней без посещения → удаление данных» относится к вкладкам Safari; к приложению с экрана
  «Домой» не применяется. Удаление при нехватке памяти остаётся возможным, `storage.persist()` на iOS
  помогает слабо → нужен регулярный экспорт.

## Стек
- **React + TypeScript + Vite** — Claude знает лучше всего, огромная экосистема.
- **Dexie.js** — обёртка над IndexedDB с версиями схемы и миграциями.
- **vite-plugin-pwa** (Workbox) — офлайн и установка на экран «Домой».
- **Tailwind CSS** — стили. Графики позже — Recharts или ECharts.
- **GitHub Pages** — хостинг кода. Cloudflare и Vercel не берём: в России их периодически замедляют.

## Дизайн MVP
Четыре экрана:
1. **Сегодня** — лента мыслей за день и поле ввода внизу, как «Избранное» в Telegram. Голос — встроенной
   диктовкой клавиатуры iOS, своё распознавание не нужно.
2. **Итог дня** — за 30 секунд: настроение 1–5, энергия, сон (лёг/встал), отметки, текст «как прошёл день».
3. **Календарь** — месяц, дни окрашены по настроению (как Year in Pixels); тап по дню → записи.
4. **Настройки** — свои метрики, граница дня, экспорт/импорт.

Стиль: системный шрифт iOS, монохром + один акцентный цвет, авто-тёмная тема, нижняя панель вкладок, крупные зоны
нажатия. Образцы — Apple Journal, Day One, Dailybean.

## Риски и решения
| Проблема | Решение |
|---|---|
| Потеря данных: iOS очистит хранилище, телефон потеряется | `storage.persist()`; экспорт в один тап (JSON + Markdown) через «Поделиться» → OneDrive / Файлы; напоминание о бэкапе раз в неделю |
| Смена адреса = пустое приложение | Адрес выбрать один раз; переезд только через экспорт/импорт |
| Запись после полуночи попадает не в тот день | Логический день с границей 04:00 |
| Будущие модули потребуют переделки базы | UUID, `updatedAt`, мягкое удаление; гибкие метрики в `metricDefinitions`; финансы — отдельной таблицей по тем же правилам |
| PWA не умеет локальные уведомления | Автоматизация в «Командах» iOS: в 22:00 уведомление «Запиши день» / открыть дневник |
| Нет Apple Health в PWA | В MVP сон и самочувствие вручную; позже — «Команды» или Capacitor |
| Анализ записей и приватность | В приложении нет ИИ и API-ключей; Claude Code на ПК читает экспортированные Markdown-файлы |
| История из Dailybean | Модель настроения совместима; импорт — если Dailybean отдаёт экспорт (проверить) |

## Связка с личной папкой (Фаза 2)
- Экспорт файлов `ГГГГ-ММ-ДД.md` в папку OneDrive на ПК — отдельную папку дневника, не в INBOX базы.
- Анализ и запись выводов в личную базу делает сессия Claude Code в зоне LIFE (из сессии этого продукта
  доступ к личной базе закрыт).
- Позже — автовыгрузка через OneDrive API прямо из приложения.
